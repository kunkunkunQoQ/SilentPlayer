# SilentPlayer v1.0.2

## SilentPlayer v1.0.2

这一版没有动播放内核，**全部围绕"日常手感"**：新增十余项小功能，修掉 6 个实际会遇到的问题，
并移除 1 项得不偿失的功能。

### 新增

- **托盘菜单「打开文件…」**：用系统文件对话框选音频文件，**始终可用**（不论是否在播放、窗口是否隐藏）。
  此前打开文件只能靠命令行、拖到窗口或双击文件关联——而窗口平时是隐藏的，等于没有可发现的入口。
- **托盘左键单击切换显示/隐藏**：单击切换，双击确保显示（此前只能"显示"，隐藏必须去点关闭按钮）。
- **托盘悬停显示当前播放**：提示文字为 `SilentPlayer — 文件名（状态）`。
- **托盘菜单顶部显示当前文件名**（灰色禁用项，仅在有文件时出现）。
- **托盘菜单显示快捷键提示**：播放/暂停一项右侧标注 `空格`。
- **关闭窗口后一次性提示**：静音气泡提示"仍在后台播放，左键托盘图标可再次打开"（每次运行只提示一次）。
- **副标题显示当前输出模式**：开着「输出到麦克风」时显示 `正在播放 · 输出到麦克风`，
  一眼就知道为什么自己听不到。
- **鼠标滚轮调音量**：窗口**任意位置**滚轮 ±5%（进度条、音量条、按钮上方都一样）。
- **键盘快捷键**：空格 = 播放/暂停，← / → = 快退/快进 5 秒，Esc = 隐藏窗口。
- **进度条与音量条都"点哪跳哪"**：点轨道任意位置直接跳到该位置（原生控件只会把滑块挪一页）。
- **长文件名悬停显示完整名**：文件名过长会省略，鼠标悬停即可看到全名。
- **命令行控制命令**：`--toggle` / `--stop` / `--show` / `--exit` / `--volume=<0-100>`，
  由已运行的实例执行，方便脚本或快捷键工具调用。
- 打开失败时**错误码附人话原因**，例如 `0xC00D36C4（格式不受支持，或文件已损坏）`。

### 修复

- **崩溃后残留导致下次启动听不到声音**：上次是「输出到麦克风」状态被强制结束（崩溃 / 任务管理器），
  按应用路由设置会残留在系统里，下次启动播放器仍被路由到虚拟麦克风 → 现在启动时会先清一次，
  再延迟修正一次，默认始终回到"正常听歌"。
- **退出时清理按应用路由**：不留持久化痕迹。
- **光标在进度条上滚轮会误改播放位置**：原生控件把滚轮当成"挪滑块"，一滚就跳 2%（约 2.4 秒）
  → 现在滚轮统一只调音量。
- **高对比度主题适配**：副标题/时间/百分比的灰色改用系统色，不再是硬编码值。
- **`--volume=abc` 不再被当成 0%**（非法值直接忽略）。
- **空闲时副标题不再带模式后缀**（原来会显示"未打开文件 · 输出到麦克风"）。

### 移除

- **系统媒体键支持**：原先用 `RegisterHotKey` 抢占键盘的播放/暂停、停止键。
  但它是**全局独占**——一旦注册，其它播放器和系统自身的媒体键处理就收不到这两个键了。
  对一个"偶尔放个音频"的静默播放器来说，抢走全局媒体键的代价大于收益，因此整项移除。
  **窗口内的快捷键（空格 / ← → / Esc / 滚轮）全部保留。**

### 说明

- 仍是单个 `SilentPlayer.exe`，**无第三方库、无安装程序**，单 EXE 双架构
  （x64 原生 + Windows 11 on ARM64 经 x64 模拟层运行）。
- 「输出到麦克风」基于系统**按应用音频路由**（`IAudioPolicyConfigFactory`）实现，只影响本播放器，
  不改系统默认设备；需要系统存在虚拟麦克风设备（如 SteelSeries Sonar）。
- 托盘菜单项**位置**会随"当前有没有加载文件"变化（顶部文件名项时有时无）。
